# Force Survival Mode

Force Survival Mode is a restrictive datapack for Minecraft that forcefully sets all players to Survival mode every
tick.

Even if someone switches to Creative or Spectator using commands, the datapack immediately reverts them back.  
Ideal for challenge maps, servers with strict rules, or adventure setups where Creative access must be completely
blocked.

## Features

- Forces Survival gamemode every game tick
- Works on all players, including operators
- Prevents use of Creative or Spectator mode at all times

## Installation

- Download the [datapack](https://github.com/Neluxx/force-survival-mode/releases/latest)
- Move the datapack inside ``.minecraft/saves/<world>/datapacks``
  ([How to find .minecraft?](https://minecraft.wiki/w/.minecraft#Locating))
- Reload the world or run ``/reload``
